# Records you can ask about

The coordination desk is a database with commands. A manager asks what is requested, reserved, received or overdue, then records the decision through the same path. Read-only HTML views and paperwork are generated from the records.

A screen gives a field worker immediate mobile access, map context, drag-and-drop work and offline capture. This base does not provide those experiences, a public portal, authenticated multi-user access, notification delivery or service dispatch. It is useful for an internal exercise and coordination desk without them. Enterprise DNA scopes any additional interface or integration around the customer's procedures.

The database remains the record. Claude Code, Codex, OpenCode or Cursor is a door into it. Never introduce a second workflow library or a separate database per agent.
